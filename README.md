# crypticonband.com

Static site for Crypticon (black metal, Atlanta GA), hosted on GitHub Pages.

| File | Page |
|---|---|
| index.html | Home: next show, latest release, announcements |
| shows.html | Upcoming and past dates |
| music.html | Bio, lineup, discography, listen links |
| merch.html | Merch (display only, "available at shows") |
| gallery.html | Live photos and videos |
| epk.html | Promoter press kit. **Unlisted**: not in the menu, hidden from search engines. Send the link directly. |

- Logo: replace `assets/logo.svg` (placeholder).
- Styles: `assets/style.css`.
- Anything tagged "Placeholder" or "Example" is mock content to replace.
- `CNAME` points GitHub Pages at crypticonband.com. Don't delete it.
